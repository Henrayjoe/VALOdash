Bring in results from your Google Sheet

Use two tabs, Clients and Results. In Google Sheets choose File → Share → Publish to web, pick each tab, choose CSV, and paste the links below. Each sync replaces the data on this device with what is in the sheet.

Sheet columns (copy into row 1 of each tab)

Clients tab


      

      
Results tab. Columns are grouped test by test, and the copy button adds a row above them naming each test. One row per client per test day. Leave any test blank if you didn't run it. Column order doesn't matter to the dashboard; the header spelling does. side_affected is L, R or None; category is Tendon, Rehab, Athlete or General; phase (1–4) is optional, otherwise it is worked out from the criteria.

      

      

    


    

      Reference ranges (used for the bars and the ring)
      
The low end scores 20/100, the high end 80/100. Football holds the WSL (women) and Premier League (men) bands from your Roar dashboard, with the source under each test. General holds starting values for active adults: replace them with the VALD Hub normative bands for each test as you use them. Footballers use the football set automatically (from the sport column); set norm_set on the Clients tab to override. Tests missing from the football set fall back to general.
